Foreflight Overlays

These KML files contain helpful guidance for our local practice area procedures, including:

  • Tower-preferred airport arrival gates
  • Local practice area boundaries
  • Distinct air-to-air reporting points
  • Airstrips/helipads not depicted on FAA Charts

Visit the Arrival Gates page to learn more about how we use this overlay in our local area.

Adding to ForeFlight

1

Download the overlay

Click the download button above to save the file to your device.

Save locally to "Files" on Apple devices.

2

Import to ForeFlight

  • Select the "Open in..." option after download
  • Select the ForeFlight app from the Open In list
  • Save the file to: "Custom Content," then "Custom Map Layers"
    • 3

    Enable the Overlay

  • On your main Map display, tap the upper left layer icon
  • Scroll down to find the overlay near the bottom and select it

    • Deleting old versions

    1

    Open ForeFlight, select "More" in the bottom right corner

    2

    Select "Custom Content" then "Custom Map Layers"

    3

    Swipe left or use Edit to delete any unneeded overlays

    Multi-layer

    If you want to toggle the air-to-air reporting points, this makes it possible. The Base layer is just boundaries and arrival gates, and the Points layer labels towns/distinct visual points for shared reporting.
