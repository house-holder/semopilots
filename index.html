About This Overlay

This KML file contains helpful guidance for our local practice area procedures, including:

  • Five tower-approved airport arrival gates
  • Our local practice area boundaries
  • Visually distinct air-to-air reporting points
  • Airstrips and helipads not depicted on the FAA Charts

Visit the Procedures page to learn more about how we use this overlay to work efficiently within our local area.

Adding to ForeFlight

1

Download the overlay

Click the download button above to save the file to your device.

Save locally to "Files" on Apple devices.

2

Import to ForeFlight

  • Select the "Open in..." option after download
  • Select the ForeFlight app from the Open In list
  • Save the file: "Custom Content," then "Custom Map Layers"
    • 3

    Enable the Overlay

  • On your main Map display, tap the upper left layer icon
  • Scroll down to find the latest CGI Overlay near the bottom, and tap to enable

    • Cleaning up old versions

    1

    Open ForeFlight, select "More" in the bottom right corner

    2

    Select "Custom Content" then "Custom Map Layers"

    3

    Swipe left or use Edit to delete any unneeded overlays
