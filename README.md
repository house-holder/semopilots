# SEMO Pilots

Local resource for students and pilots at Cape Girardeau Regional Airport (KCGI).

## Local Development

**Requirements**
- tmux
- Node.js
- Wrangler (`npm install -g wrangler`)
- browser-sync (`npm install -g browser-sync`)

**Start local dev server**
From repo root: `./dev.sh start`

**Stop local dev server**
And at the end of a work session: `./dev.sh stop`
